> AI 负责创作剧情，视觉小说负责呈现剧情。当角色不再只是聊天框里的一段文字，AI 互动还能变成什么样？

## 1. 前言：AI 角色扮演的另一种可能

随着大语言模型的发展，AI 角色扮演已经成为一种相当有趣的应用场景。

用户可以通过角色卡、世界观设定和提示词，让 AI 扮演一个拥有独立性格、背景和行为逻辑的角色，并通过持续对话推动故事发展。

但传统的 AI 角色扮演通常存在一个比较明显的局限：**无论故事多么精彩，最终呈现出来的依然只是一段段文字。**

角色的表情需要自己想象，场景的变化需要自己脑补，背景音乐和语音演出更是无从谈起。

那么，有没有可能把 AI 的自由对话能力与传统视觉小说的表现形式结合起来？

这就是本文想介绍的开源项目：**AnimaVN**。

## 2. AnimaVN 是什么？

AnimaVN 是一个 AI 驱动的视觉小说引擎。它试图将传统 AI 角色扮演与 Visual Novel（视觉小说）结合，让模型生成的剧情以更接近 Galgame 的形式呈现。

与传统视觉小说不同，AnimaVN 并不完全依赖预先编写好的固定剧本。

玩家可以直接输入自己的想法，与 AI 角色自由交流，模型根据上下文生成后续剧情，再由前端负责对白展示、立绘切换、场景变化和其他演出效果。

简单来说：

- AI 模型负责生成剧情和角色对白。
- 视觉小说界面负责呈现剧情。
- 角色素材负责提供立绘、表情和声音。
- 玩家通过自由输入参与故事发展。

它并不是简单地给聊天窗口加一张背景图，而是尝试构建一套完整的 AI 互动叙事体验。

项目地址：[JayziLi/AnimaVN](https://github.com/JayziLi/AnimaVN)

### 3.3 玩家

![玩家人设面板](/images/posts/animavn/2026-11-29-02-38-19.png)

「玩家人设」用于告诉 AI 你在故事里是谁、长什么样，以及你和角色是什么关系。

| 功能 | 作用 |
| --- | --- |
| 人设列表 | 保存多套玩家身份，点击其中一套即可启用，方便在不同故事中切换。 |
| 「当前」标记 | 表示正在使用的人设。截图中启用的是「用户」。 |
| ＋新建人设 | 创建一套新的玩家身份，截图中已经展开了创建表单。 |
| 名字 · `{{USER}}` | 填写你在故事中的名字，例如「旅行者」。提示词里的 `{{USER}}` 会使用这个名字。 |
| 人设描述 | 填写外貌、性格、背景，以及与角色的关系。如果预设启用了玩家人设块，这段描述会填入 `personaDescription`。 |
| 创建并启用 | 保存新的人设，并立即切换使用。 |
| 取消 | 退出本次创建。 |

**填写示例**

**名字**：林澈

**人设描述**：19 岁，电子信息工程专业的大一学生。黑色短发，性格慢热，喜欢研究电子设备。和角色认识多年，熟悉后相处自然，也会互相开玩笑。

写清楚玩家和角色的关系，能帮助 AI 把握称呼和互动方式。

### 3.4 设置

![设置面板](/images/posts/animavn/2026-11-29-02-47-54.png)

设置分为聊天、宏和世界书三部分，分别用于调整阅读和输入体验、在提示词中自动填入信息，以及控制哪些背景资料会发送给 AI。

#### 3.4.1 聊天

聊天设置用于调整消息的显示方式和输入框的操作习惯。

| 功能 | 作用 |
| --- | --- |
| 排版 | 提供气泡、对向、文档、紧凑、剧本五种样式。对向类似即时通讯，文档适合阅读长篇剧情，剧本突出人物名字和台词。 |
| 字号 | 调整正文、昵称和模型信息的整体大小。 |
| 行距与消息列宽度 | 调整行与行之间的距离和每行的长度，也可以让消息铺满聊天区。 |
| 头像 | 调整头像大小，并选择圆角、方形或圆形。文档和剧本排版不显示头像。 |
| 回车键 | 选择按 Enter 发送消息或换行。「自动」模式会根据电脑和手机采用不同的操作方式。 |
| 对话高亮 | 为成对引号中的台词单独上色，方便区分台词和叙述，也可以调整高亮颜色。 |

#### 3.4.2 宏

宏是提示词里的自动替换标记。例如，`{{char}}` 会替换为角色名，`{{user}}` 会替换为玩家名。

| 功能 | 作用 |
| --- | --- |
| 内置宏 | 查看宏的写法、说明和当前值，支持搜索，点击宏名即可复制。 |
| 对话变量 | 保存当前对话使用的数据，例如剧情进度或某个事件是否发生。变量随这条对话保存。 |
| 全局变量 | 保存多条对话都可以读取的数据，变量保存在本机。 |
| 自定义宏 | 给一段常用文字起名字，之后用 `{{名字}}` 引用这段文字。 |
| 试一试 | 预览宏替换后的文本。在这里测试时，变量的变化不会保存。 |

#### 3.4.3 世界书

世界书用于存放人物、地点、组织和世界观等资料。这一页设置的是程序如何查找关键词，以及把哪些条目加入提示词。

| 功能 | 作用 |
| --- | --- |
| 扫描条数 | 决定从最近多少条消息中查找关键词。 |
| 最少触发数 | 如果触发的条目数量不足，就继续向更早的消息查找，也可以设置查找上限。 |
| 带上说话人的名字 | 将说话人的名字一起扫描，让人名也能触发相关条目。 |
| 区分大小写 | 决定英文关键词的大小写是否必须一致。 |
| 全词匹配 | 要求英文关键词以完整单词出现，避免匹配到其他单词的一部分。此选项不影响中文关键词。 |
| 递归扫描 | 已触发条目的正文也可以触发其他条目，并可限制扫描轮数。 |
| 预算 | 限制世界书资料可占用的上下文比例或 token 数量。超出预算的条目不会加入提示词。 |
| 互斥分组 | 同组多个条目符合条件时，可以优先选取关键词命中数最多的条目，也可以按权重随机选取。 |

### 3.5 插件

![插件面板](/images/posts/animavn/2026-11-29-02-48-27.png)

插件用于配置立绘、语音、背景、背景音乐和 CG 等视觉小说功能，以及这些功能需要的提示词和辅助服务。部分功能需要先给角色绑定对应素材，或配置可用的服务连接。

#### 3.5.1 立绘
立绘功能用于展示角色形象，并根据对话中的表情信息切换对应图片。可以到游戏官网或 [Pixiv（P 站）](https://www.pixiv.net/) 找素材，使用前记得看授权。

| 功能 | 作用 |
| --- | --- |
| 立绘开关 | 控制是否启用立绘功能。 |
| 立绘包 | 为角色选择已导入的立绘素材，例如平静、微笑、惊讶等不同表情。 |
| 快速预览 | 查看角色立绘的显示效果，方便检查素材。 |
| 人物大小 | 调整立绘在画面中的大小。 |
| 头的高度 | 调整人物头部在画面中的位置，改善不同素材的显示效果。 |
| 标签来源 | 选择由聊天 AI 输出表情标签，或交给 Jev 标注。 |
| 标签格式 | 设置程序识别表情标签时使用的格式。 |
| 高级设置 | 调整提示词块，以及立绘与语音情绪、CG 差分之间的对应关系。 |

#### 3.5.2 语音
语音功能用于将角色台词转换成声音，需要先配置语音服务并为角色选择音色。

| 功能 | 作用 |
| --- | --- |
| 语音开关 | 控制是否播放角色语音。 |
| 音色 | 为角色选择已配置的声音。 |
| 快速预览 | 试听当前音色，检查语音效果。 |
| 文字和语音 | 选择先显示文字，或等待语音准备好后再显示。 |
| 最多等 | 在等待语音模式下，设置最长等待时间。 |
| 语音情绪 | 选择让语气跟随表情变化，或保持不变。 |
| 缓存 | 查看和清理已生成的语音缓存。 |
| 配对表 | 查看每张立绘对应的语音情绪，方便检查表情和语气是否协调。 |

#### 3.5.3 背景
背景功能用于展示故事发生的场景，并根据剧情信息切换背景图片。AnimaVN 自带一些示例背景，我刚上手时就先用的这些。

| 功能 | 作用 |
| --- | --- |
| 背景开关 | 控制是否启用背景切换功能。 |
| 场景包 | 为角色绑定包含背景图片的场景素材包。 |
| 快速预览 | 查看场景图片的显示效果。 |
| 标签来源 | 选择由聊天 AI 输出场景标签，或交给 Jev 判断。 |
| 标签格式 | 设置背景切换标签的识别格式。 |
| 高级设置 | 调整背景提示词块，以及使用 Jev 时的判断门槛和问法。 |

#### 3.5.4 BGM
BGM 即背景音乐，用于配合日常、温馨、紧张、伤感等不同剧情氛围。

| 功能 | 作用 |
| --- | --- |
| BGM 开关 | 控制是否启用背景音乐功能。 |
| 场景包 | 为角色绑定包含背景音乐的素材包。 |
| 快速预览 | 试听素材包中的音乐。 |
| 标签来源 | 选择由聊天 AI 输出音乐标签，或交给 Jev 判断。 |
| 标签格式 | 设置背景音乐切换标签的识别格式。 |
| 高级设置 | 调整音乐提示词块，以及使用 Jev 时的判断门槛和问法。 |

#### 3.5.5 CG

CG 功能用于在剧情中展示特定的插画画面。它负责调用已有素材，图片需要提前导入。

| 功能 | 作用 |
| --- | --- |
| CG 开关 | 控制是否启用 CG 功能。 |
| CG 包 | 为角色绑定可使用的 CG 素材。 |
| 快速预览 | 查看 CG 图片及其差分。 |
| 标签来源 | 选择由聊天 AI 输出 CG 标签，或交给 Jev 判断。 |
| 标签格式 | 设置 CG 标签的识别格式。 |
| 差分配对 | 设置不同立绘对应哪张 CG 差分。 |
| 高级设置 | 调整 CG 提示词块，以及使用 Jev 时的判断门槛和问法。 |

#### 3.5.6 外语

外语功能用于配合日语音色和日中双语台词，并控制字幕的显示方式。

| 功能 | 作用 |
| --- | --- |
| 字幕 | 选择日中双语，或只显示中文。 |
| 隐藏前文日语 | 隐藏当前对话中已有回复的日语显示，也可以恢复。 |
| 实机预览 | 查看双语字幕或中文字幕的显示效果。 |
| 这次发出去的 | 查看当前对话将发送的外语指令，以及是否使用精简版本。 |
| 块的原文 | 查看和修改外语提示词块。 |
| 精简版原文 | 查看标签交给 Jev 处理时使用的精简外语指令。 |

外语指令是否发送，会结合当前角色、音色语言及相关配置自动判断。

#### 3.5.7 Jev 标注

Jev 标注用于分析回复中的说话人、表情、背景、音乐和 CG 信息，辅助驱动画面与语音。

| 功能 | 作用 |
| --- | --- |
| 连接配置 | 设置服务地址、API Key 和模型名。 |
| 测试 | 检查 Jev 服务是否能够连接。 |
| 哪几路交给 Jev | 分别选择哪些标签由聊天 AI 输出，哪些交给 Jev 标注。 |
| 带上一条回复 | 携带上一条回复中的部分句子，为判断提供上下文。 |
| 立绘和文字同步 | 控制立绘变化与文字显示的同步。 |
| 说话人门槛 | 调整说话人判断的门槛，影响台词归属及语音朗读。 |
| 试判 | 使用最新一条回复测试，查看逐句判断结果、耗时和用量。 |
| 用量 | 查看今天、近 7 天、本月及全部的请求次数和 token 用量。 |
| 高级设置 | 自定义判断问法，并提供两条队列的试用选项。 |

使用 Jev 前需要配置可用的服务连接；具体调用费用以所使用的服务为准。

#### 3.5.8 语音服务

语音服务用于管理文字转语音的连接，供角色音色调用。

| 功能 | 作用 |
| --- | --- |
| 连接管理 | 添加和管理不同的语音服务连接。 |
| 服务类型 | 支持 GPT-SoVITS、IndexTTS-2.5、Fish Audio，以及兼容的中转站服务。 |
| 地址 | 填写对应语音服务的接口地址。 |
| 认证信息 | 根据服务要求配置 API Key 或配对码等信息。 |
| 模型配置 | 根据服务类型选择或填写语音模型，部分服务可读取可用模型列表。 |
| 测试 | 检查连接是否可用。 |

不同服务的配置项目有所区别，填写时需要与实际使用的语音后端对应。

#### 3.5.9 自动补块

自动补块用于在当前预设缺少所需插件提示词块时，自动补充相关内容。

| 功能 | 作用 |
| --- | --- |
| 缺块时补上 | 开启后，在发送时补充当前需要且预设中缺少的插件提示词块。 |
| 本次补充预览 | 查看当前角色、预设和插件状态下，这次会补充哪些内容。 |

该功能可以减少手动向预设添加插件提示词块的操作，但仍需要先配置对应素材或服务。

#### 3.5.10 表情认法

表情认法用于选择程序如何识别和匹配表情词。

| 功能 | 作用 |
| --- | --- |
| 认词记录 | 切换到基于认词记录的表情识别方式。 |
| 旧算法 | 使用原有的表情识别算法。 |
| 本地小模型 | 查看辅助识别模型是否已安装。对于不能直接按名称匹配的词，相关自动识别能力需要模型支持。 |

#### 3.5.11 通用操作

插件页面还提供角色选择、作用范围提示和预设管理等通用功能。

| 功能 | 作用 |
| --- | --- |
| 看哪张卡 | 切换正在查看和配置的角色卡。 |
| 在用状态 | 显示所选角色是否正在使用对应功能。 |
| 作用范围 | 区分全局、当前角色和本机设置；带有「所有卡」提示的开关会影响所有角色。 |
| 这张卡另设 | 对支持单独配置的选项，为当前角色设置独立参数。 |
| 恢复成全局 | 取消当前角色的单独设置，重新使用全局配置。 |
| 恢复默认 | 将对应选项恢复为默认值。 |
| 提示词块管理 | 查看插件提示词内容，并将对应块加入当前预设、开启、关闭或移出预设。 |
| 素材入口 | 跳转到角色编辑器或素材管理页面，配置立绘、声音和场景等素材。 |

### 3.6 素材管理

![素材查看与编辑](/images/posts/animavn/2026-11-29-03-00-49.png)

素材管理用于导入、编辑和绑定立绘、声音、背景、BGM 和 CG。一套素材可以绑定到多张角色卡，方便在不同故事中重复使用。

#### 3.6.1 立绘

立绘是角色在画面中显示的形象。一套立绘可以包含多张「差分」，例如同一个角色的平静、微笑和惊讶表情。
如果手头的立绘只有一张，也可以用支持出图的工具制作表情差分。
| 功能 | 作用 |
| --- | --- |
| 添加差分 | 一次上传多张立绘图片，文件名会用作差分名。 |
| 名称、描述与别名 | 说明每张立绘对应的表情或动作，也可以用别名匹配不同说法，例如「开心」和「高兴」。 |
| 默认差分 | 指定这套立绘默认显示哪张图。 |
| 位置与动效 | 调整立绘在画面中的位置和入场效果，可以换一张背景预览。 |
| 启用与停用 | 控制某张差分是否可在游戏中使用。 |

#### 3.6.2 声音
声音页用于管理角色的音色及不同情绪下的发声方式。新建声音前，需要先在「插件 → 语音服务」里添加连接。

| 功能 | 作用 |
| --- | --- |
| 新建声音 | 设置音色名称和对应的语音服务，具体选项随服务类型而变化。 |
| 导入声音 | 导入声音包，或通过 `refs.json` 导入参考音频配置。 |
| 参考音频与参考文本 | 对支持参考音频的服务，填写音频路径和音频中实际说出的文字。 |
| 情绪参考 | 为不同情绪配置参考音频或参数。情绪名或别名可以与立绘差分对应。 |
| 试听 | 输入一段台词并选择情绪，试听合成效果。 |

#### 3.6.3 背景
背景是角色身后的场景图，例如教室、街道或房间。背景和 BGM 可以放在同一个场景包里，并分别绑定到角色卡。

| 功能 | 作用 |
| --- | --- |
| 添加背景 | 批量上传场景图片，文件名会用作背景名称。 |
| 描述与别名 | 说明场景的地点、时间或氛围，并设置便于识别的别名。 |
| 默认 BGM | 给背景指定一首搭配的曲子，也可以选择切换背景时保持当前音乐。 |
| 竖屏焦点 | 调整手机竖屏时优先保留的画面区域，可以在预览中拖动裁切框。 |
| 启用与停用 | 控制某张背景是否可在游戏中使用。 |

#### 3.6.4 BGM
BGM 是剧情播放时使用的背景音乐，可以为不同氛围准备不同的曲子，也可以在 B 站搜索允许使用的视觉小说音乐素材包。

| 功能 | 作用 |
| --- | --- |
| 添加曲子 | 一次上传多首音乐，文件名会用作曲名。 |
| 描述与别名 | 标记曲子的氛围和适合使用的场景，例如「紧张」或「回忆」。 |
| 试听 | 在素材页直接播放曲子，检查音频和氛围。 |
| 封面曲 | 将一首已启用的曲子设为标题画面的音乐。 |
| 启用与停用 | 控制某首曲子是否可在游戏中使用。 |

#### 3.6.5 CG

CG 是用来表现特定剧情画面的插画，例如角色重逢或一起看烟花。同一个画面可以附带不同表情的版本。

| 功能 | 作用 |
| --- | --- |
| 添加构图 | 上传一张或多张 CG 主图，每张图对应一个剧情画面。 |
| 描述与别名 | 说明画面里发生了什么、适合在哪类剧情中出现，供 AI 或 Jev 选择。 |
| 表情差分 | 为同一画面添加不同表情的版本，通过名称或别名与立绘差分对应。 |
| 竖屏焦点 | 调整手机竖屏时保留的区域。同一构图的表情差分沿用这个焦点。 |
| 启用与停用 | 控制 AI 或 Jev 是否可以选用这张 CG。 |

#### 3.6.6 导入与绑定

导入时可以先把文件放进素材库，也可以根据导入选项把素材直接挂到角色卡上。之后可以在素材页查看或调整绑定关系。

| 功能 | 作用 |
| --- | --- |
| 导入 | 选择文件、文件夹，或直接拖入受支持的素材和压缩包。 |
| 搜索与筛选 | 按素材名称、关联角色等信息查找，也可以筛选已绑定或未绑定的素材。 |
| 绑定角色卡 | 将素材分配给一张或多张角色卡。取消绑定后，素材仍保留在库中。 |
| 导入记录 | 查看最近 50 次导入。撤销某次导入会移除该次新建的卡和素材包，并解除该次添加的绑定。 |
| 清理 | 将没有被素材包、角色卡或备份引用的文件移到回收区，暂存 30 天后删除。 |

### 3.7 API 连接

API 连接用于配置 AnimaVN 生成对话和剧情时使用的模型。可以保存多套连接，在游戏左上角的「模型」窗口切换。「当前启用」表示正在使用的连接。调试台的 API 管理与游戏内的连接设置共用同一份配置。

#### 3.7.1 连接类型
使用 API 服务时，按服务要求填写密钥。使用界面中的 ChatGPT 订阅连接时，通过浏览器登录和授权。
| 类型 | 作用 |
| --- | --- |
| OpenAI 兼容 | 用于接入采用 OpenAI 接口格式的服务，例如 OpenRouter 或本地 Ollama。按服务提供的信息填写接口地址、模型名和所需密钥。 |
| Anthropic | 用于接入采用 Anthropic 接口格式的服务，例如 Claude API。按服务要求填写地址、密钥和模型名。 |
| ChatGPT 订阅（Plus / Pro） | 通过系统浏览器登录并授权，然后从可用模型中选择。这个选项通过账号登录完成连接，无需填写 API Key。 |
| Mock（本地测试） | 使用程序内置的模拟回复，方便在没有外部模型服务时测试界面和对话流程。 |

#### 3.7.2 连接配置

| 功能 | 作用 |
| --- | --- |
| 名称 | 给连接起一个便于辨认的名字，例如「本地 Ollama」。这个名字用于区分连接。 |
| Base URL | 填写模型服务的接口地址。使用中转服务时，填写该服务提供的 API 地址。 |
| API Key | 填写对应服务的密钥。编辑已有连接时，如果界面提示密钥已保存，留空会继续使用原来的密钥。 |
| 模型名 | 填写服务要求的模型标识，也可以刷新「可用模型」列表后选择。 |
| 流式输出 | 开启后，回复会边生成边显示。如果服务不支持流式输出，可以关闭后再试。 |
| 思考 | 对支持此选项的模型调整思考档位。选择「默认」时，沿用服务自身的设置。 |

#### 3.7.3 连接测试

保存连接后，可以先点「连接」检查服务是否可达，再点「发送测试消息」确认所选模型能否正常回复。

| 功能 | 作用 |
| --- | --- |
| 刷新可用模型 | 从服务获取模型列表，方便核对模型名。 |
| 连接 | 通过读取模型列表检查接口能否连通。 |
| 发送测试消息 | 向所选模型发送一条消息，并显示实际收到的回复。 |

#### 3.7.4 判断模型 Jev

API 连接页也会显示 Jev 的密钥配置状态。Jev 用于判断回复中的说话人、表情、背景、BGM 和 CG 标签，服务地址、模型名和密钥在「插件 → Jev 标注」里单独设置。

### 3.8 角色卡

![角色卡列表](/images/posts/animavn/2026-11-29-03-18-04.png)

角色卡用来定义 AI 在故事中扮演的角色，包括她是谁、平时怎么说话、故事从哪里开始，以及在视觉小说里使用哪些素材。角色卡描述的是 AI 扮演的人物，玩家人设描述的是你在故事中的身份。

#### 3.8.1 基础资料

| 功能 | 作用 |
| --- | --- |
| 角色名与头像 | 设置角色在列表和对话中显示的名字和头像。 |
| 角色描述 | 描述角色的外貌、经历、行为习惯，以及她和玩家的关系。 |
| 性格 | 概括角色的性格特点，例如「说话直接，关心别人时会先问对方有没有吃饭」。 |
| 情景 | 交代对话发生的地点、时间和背景，例如「放学后，两人在下雨的校门口碰面」。 |
| 对话示例 | 写几段角色和玩家的示例对话，给 AI 参考角色的用词和语气。 |
| 创作者注释 | 写给使用角色卡的人看的说明，例如玩法或推荐搭配。这部分不会发送给 AI。 |

#### 3.8.2 开场白

![角色卡开场白](/images/posts/animavn/2026-11-29-03-24-55.png)

开场白是新建对话时角色发出的第一条消息，可以同时写入场景、动作和台词。

| 功能 | 作用 |
| --- | --- |
| 主开场白 | 设置新建对话时默认使用的开头。 |
| 其他开场 | 给同一个角色准备不同的故事起点，例如「初次见面」和「多年后重逢」。 |
| 从这一条开始 | 选中某条开场白，直接以它开启一段新对话。 |

#### 3.8.3 预设与世界书

| 功能 | 作用 |
| --- | --- |
| 绑定预设 | 为角色卡指定一套预设，控制角色资料、玩家人设和对话历史等内容如何组装成提示词。 |
| 提示词覆盖 | 在预设允许时，用这张角色卡的指令替换对应的提示词块。 |
| 角色世界书 | 为这张卡添加人物、地点或背景故事等资料。关键词条目在匹配时加入提示词，常驻条目每轮都参与组装。 |
| 提示词预览 | 查看角色卡的哪些内容会进入提示词，以及世界书条目预计是否触发。 |

#### 3.8.4 素材与导入导出

| 功能 | 作用 |
| --- | --- |
| 素材绑定 | 为角色选择立绘、声音、背景、BGM 和 CG，供视觉小说模式使用。 |
| 新建与复制 | 从空白卡开始，或复制一张已有的卡，在副本上调整设定。 |
| 导入角色卡 | 导入含角色数据的 PNG 卡、JSON 卡或 AnimaVN 角色包。 |
| 只导卡（.json） | 导出角色卡本身，适合单独分享文字设定。 |
| 角色包（.animavn） | 将角色卡与选定的素材一起打包，方便分享或迁移到另一台电脑。 |
| 给酒馆用户（PNG + 表情 ZIP） | 将角色卡导出为 PNG，并单独打包表情素材，方便在酒馆中导入。 |

## 4. 卡编辑器

卡编辑器是集中修改角色卡的工作区。顶部的「资料」和「素材」对应两个页面。左侧目录可以跳到指定字段，中间是编辑区，右侧可以设置绑定并查看提示词的 Token 用量。

### 4.1 资料

「资料」页可以编辑角色设定、开场白和创作者信息。左侧目录会标出哪些字段参与提示词组装，哪些用于开场或给玩家阅读。

![卡编辑器的资料页](/images/posts/animavn/2026-11-29-03-33-08.png)

| 功能 | 作用 |
| --- | --- |
| 标签与元数据 | 设置角色头像、名称、创作者、版本和标签，方便识别和管理角色卡。 |
| 创作者注释 | 填写给玩家看的说明，例如角色玩法、素材来源和授权信息。注释不会发送给 AI。 |
| 角色描述、性格摘要与情景 | 写入角色设定、性格特点和故事发生的背景。 |
| 对话示例 | 写几段示例，让 AI 参考角色的说话方式和互动习惯。 |
| 主提示词覆盖与历史后指令 | 在预设允许时，替换对应的提示词块，例如为这张卡设置专用的叙事规则。 |
| 世界书 | 编辑这张卡的人物、地点和背景设定，并查看条目的触发状态。 |
| 开场白 | 设置新对话中角色发出的第一条消息，也可以添加多个备选开场。开场白会出现在对话里。 |

目录里的 `!` 提醒你检查该字段的实际发送情况。如果字段显示「填了也不会发出去」，可以先检查当前预设里是否有对应的提示词块，以及该块的设置。

### 4.2 绑定与上下文预算

右侧栏可以给当前角色卡绑定玩家身份和预设，并查看各类内容占用了多少上下文。

| 功能 | 作用 |
| --- | --- |
| 绑定玩家身份 | 为这张卡指定一套玩家人设。选择「不绑定」时，使用这张卡不会自动切换玩家身份。 |
| 绑定预设 | 为这张卡指定一套提示词预设。选择「不绑定」时，沿用对话记住的预设。 |
| Token 分布 | 查看角色卡、预设、世界书、示例对话、历史和玩家人设各自的预计用量。 |
| 上下文预算 | 设置可用的上下文预算，并查看当前使用比例和截断状态。 |

### 4.3 素材

切换到「素材」页，可以为正在编辑的角色卡选择视觉小说模式使用的素材。

![卡编辑器的素材页](/images/posts/animavn/2026-11-29-03-32-28.png)

| 功能 | 作用 |
| --- | --- |
| 立绘 | 绑定角色的立绘包，让游戏能显示角色形象和不同表情。 |
| 声音 | 为角色选择音色，用于合成台词。 |
| 背景与 BGM | 为角色绑定可用的场景图片和背景音乐。 |

### 4.4 保存、导出与试跑

| 功能 | 作用 |

| 删除角色卡 | 删除当前角色卡。 |

## 5. 技术架构

AnimaVN 的浏览器端负责组装提示词和呈现视觉小说画面。后端负责调用模型、读写数据，并对接语音合成服务。

| 模块 | 技术 |
| --- | --- |
| 前端 | React、TypeScript、Vite |
| 后端 | Python、FastAPI |
| 数据库 | SQLite、SQLAlchemy |
| AI 模型连接 | OpenAI 兼容接口、Anthropic 接口等 |
| 语音合成 | GPT-SoVITS 等 |
| 视觉小说演出 | 自定义前端模块 |

![AnimaVN 从玩家输入到剧情演出的流程](/images/posts/animavn/architecture.png)

一次对话开始后，浏览器会把玩家输入、角色卡、预设、世界书和相关对话历史组装成提示词，再交给后端请求模型。收到回复后，前端显示剧情，并按标签和素材配置切换立绘、背景、音乐或 CG。启用语音时，前端还会通过后端请求合成并播放台词。

这样，AnimaVN 可以沿用酒馆的角色卡、预设和世界书配置方式，同时把模型回复呈现为视觉小说。

## 6. 如何开始使用？

对于 Windows 用户，项目提供了整合包，降低了初次安装的门槛。

基本流程如下：

1. 打开 [AnimaVN 的 Windows 整合包说明](https://github.com/JayziLi/AnimaVN#快速开始)。
2. 下载 Windows 整合包。国内可从 README 指向的魔搭页面下载，也可以使用 GitHub Releases。
3. 解压到合适的目录。
4. 双击 `AnimaVN.bat`。
5. 等待服务启动并打开浏览器。
6. 配置可用的 AI 模型 API。
7. 导入角色卡，开始体验。

如果希望自行部署或参与开发，则需要准备：

- Python 3.11 或更新版本。
- Node.js 22.12 或更新版本。
- 对应的 Python 和 Node.js 依赖。
- 一个可用的 AI 模型接口。

项目支持 OpenAI 兼容接口以及 Anthropic 原生接口，也可以连接 Ollama 等本地模型服务。

语音、生图属于可选功能，不是体验基础视觉小说功能的必要条件。

详细安装步骤以项目 README 为准。

## 7. 项目的不足

当然，AnimaVN 并不是一个没有缺点的项目。

首先，完整体验需要一定的配置成本。虽然 Windows 整合包已经降低了安装难度，但模型 API、语音服务和素材配置仍然需要用户自行处理。

其次，不同模型的输出质量和指令遵循能力存在差异，这会直接影响角色扮演的连贯性以及视觉演出的稳定程度。

另外，SillyTavern 兼容层虽然已经覆盖了不少常见功能，但仍有部分扩展和预设特性没有实现。

AI 生图和语音服务也可能产生额外费用，对硬件和网络环境有一定要求。

订阅能否用来连接，取决于服务的接口和授权方式。本文介绍的界面提供 ChatGPT 订阅登录选项。

我体验时有些场景需要玩家先发一句，剧情才会往下走。

我期待以后能有更丰富的演出、更方便的角色管理，入门也能更简单。谁不想玩到自己想玩的剧情呢？

## 8. 总结

AnimaVN 最有意思的地方，并不只是把 AI 接入了一套视觉小说界面。

它尝试改变的是 AI 角色扮演的呈现方式。

过去，我们通过文字想象角色的表情、声音和所处环境；现在，我们可以让这些元素直接出现在屏幕上。

它确实提供了一种值得探索的方向：

**让 AI 不只是陪你聊天，而是陪你一起创造故事。**

（谁能不激动呢？）

如果你对 AI 角色扮演、视觉小说或者开源 AI 应用感兴趣，不妨亲自体验一下 AnimaVN。
